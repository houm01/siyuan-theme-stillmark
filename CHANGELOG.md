# Changelog

## 0.3.18 - 2026-08-10

- Keep the marketplace theme package CSS-only so it can pass current SiYuan Bazaar checks.
- Move dynamic source-site favicons and duplicate-bookmark path annotations to the optional Stillmark Workbench companion plugin while retaining the neutral link-icon fallback in the theme.
- Add a deterministic package builder that rejects `theme.js` and unexpected archive entries.

## 0.3.17 - 2026-08-10

- Add compact parent-path subtitles only to duplicate bookmark titles, with notebook and document-time fallbacks when the location alone is still ambiguous.

## 0.3.15 - 2026-08-03

- Restyle inline block references as compact wolai-inspired berry labels with no extra arrow or underline, plus a balanced dark-mode counterpart.

## 0.3.13 - 2026-07-28

- Strengthen the sage reference surfaces into clearly visible light and dark fills while keeping their saturation restrained.

## 0.3.12 - 2026-07-28

## 0.3.11 - 2026-07-28

## 0.3.10 - 2026-07-28

## 0.3.9 - 2026-07-28

## 0.3.8 - 2026-07-28

- Flatten code blocks into quiet document insets with no persistent shadow or separate header strip, a plain language label, softer surfaces, and tighter typography.

## 0.3.5 - 2026-07-28

- Tighten code-block typography, line spacing, toolbar height, content padding, controls, and depth so code sits more naturally within the document.

## 0.3.4 - 2026-07-27

## 0.3.3 - 2026-07-27

## 0.3.0 - 2026-07-15

- Refine the `Cmd + P` global search into a compact workbench with a stronger query field, denser results, quieter preview hierarchy, restrained match states, and two-mode layout support.
- Replace link-like blue inline code with high-contrast muted-berry text, a softly tinted background, and tighter corners in both modes.

## 0.2.0 - 2026-07-15

- Rework the application shell with neutral workspace surfaces, compact document tabs and docks, a quieter editor hierarchy, and restrained red active states in both light and dark modes.
- Anchor editor list hover guides to each item's marker row and delay nested first-item straights until their rounded turn completes, preventing gaps, overshoot, and corner overlap.

## 0.1.1 - 2026-07-25

- Losslessly optimize the marketplace icon to satisfy the 20 KB Bazaar limit.
- Refresh the theme asset version so existing SiYuan windows load the new favicon helper instead of retaining the CSS-only fallback.

## 0.1.0 - 2026-07-15

- Initialize Stillmark from the official SiYuan theme sample.
- Add Stillmark metadata and bilingual documentation.
- Add a neutral light and dark mode color baseline.
- Replace the sample marketplace icon with an original Stillmark icon.
- Add compact red inline code and two-mode Highlight.js syntax colors.
- Refine code blocks, block references, and file annotation references.
- Rework code blocks with a softer editor-style panel, language capsule, and clearer controls.
- Add uninterrupted 2px blue hover guides while keeping ordered-list numbers unobstructed.
- Connect nested-list guides with pixel-centered, overlapping rounded joints from parent markers to child markers, suppressing native gray guides along the active path.
- Give hyperlinks a persistent fine underline with clearer hover and keyboard-focus states.
- Show compact source-site favicons before external hyperlinks with a neutral fallback.
- Replace document-tree emoji with a compact two-tone note icon.
- Add continuous, pixel-aligned blue hover guides from expanded document-tree parents to the active child row.
- Refine table databases with a flat Notion-inspired hierarchy, hairline grids, compact rows, and two-mode interaction states.
- Reduce database-backed page attributes to a quiet borderless disclosure with muted icons and text.
